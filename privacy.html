プライバシーポリシー

制定日: 2026年10月16日
運営者: Harmony Nexus株式会社

「HN 証憑収集」（以下「本ツール」）は、Harmony Nexus株式会社が社内の経理のために利用するツールです。利用者は、本人の同意を得た当社関係者に限られます。

1. 取得する情報

利用者が許可した Gmail アカウントについて、Google の「Gmail の読み取り（gmail.readonly）」権限でメールの件名・送信元・本文・添付ファイルを読み取ります。パスワードは取得しません。

2. 利用目的

領収書・請求書・支払証明の候補を見つけ、会社の経理用 Google ドライブと管理台帳に保存するためだけに利用します。広告、販売、第三者への提供には利用しません。

3. 保存しない情報

領収書・請求書と判断しなかったメール（医療・学校・私的なやり取り・広告など）の内容は保存しません。処理記録にはメールの識別番号と処理結果だけを残します。

4. AI による判定

候補の判定に Google Cloud の Vertex AI を使います。送る内容は判定に必要な範囲に限り、カード番号・電話番号・メールアドレス等は伏せ字にします。

5. 管理

認証情報は Google Cloud の Secret Manager にのみ保管し、ファイル・ソースコード・ドライブには保存しません。本ツールはメールの削除・移動・既読化・送信を行いません。

6. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、限定的な使用の要件を含む Google API Services User Data Policy に従います。

7. 許可の取り消し

利用者はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から本ツールへのアクセスを取り消せます。
